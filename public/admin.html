After a server reset

SpaceTraders resets the whole universe weekly and every existing agent token stops working — re-register each tenant with a fresh token first (the normal sign-in flow), then run this. It truncates every shared galaxy table (jump gates, market prices, shipyard stock, system layout — all now describe a universe that no longer exists) and clears the stale game data (old ships, contracts, missions, financial history) for whichever tenants below are checked. Standing orders/doctrine settings and login sessions are left alone.
