stcommand database schema

PostgreSQL, 66 tables, built by 68 migration files. One server runs many SpaceTraders agents ("tenants"); this is everything it stores. Structure only: no data, tokens or keys.

Per-player tablesCarry tenant_id → tenants.id. Row-level security limits every query to the signed-in player, so code never filters by hand.
Shared galaxy tablesMarkets, systems, gates and yards are facts about the galaxy, read by every player and wiped at each weekly reset.
Ships by symbolShip tables key on (tenant_id, ship_symbol) with no ships table: the game API is the source of truth for ships.
Weeks kept apartuniverse_key = agent@reset date on the ledger and event tables, so last week's rows never mix with this week's.
foreign key (enforced)joined by value (not enforced)per player row-level securityshared one copy for all players
