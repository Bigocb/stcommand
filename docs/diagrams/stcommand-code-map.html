What happens on each tick

The engine is one loop per player. Ships are refreshed, routes are priced from fresh market data, the best ship gets each route, and every ship's agent takes its next step. Keepers and tours feed new prices back in. Doctrine settings steer the whole thing; the screens and the MCP tools read the same state.
